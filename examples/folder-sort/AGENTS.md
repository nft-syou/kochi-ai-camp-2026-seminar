# folder-sort

ダウンロードフォルダを、拡張子と日付で `整理済み/` に振り分ける。文書だけ「請求書 / 領収書 / その他」を判定AI(JEV)で選ぶ。
本体は `sort.mjs` 1本。設定は `.env`。記録は `docs/`。

## やってはいけないこと

- `.env` を読んで値を表示・コミットしない
- `--apply` を人間の確認なしに実行しない。まず dry-run の結果を見せる
- 同名ファイルを上書きしない(いまの実装はスキップする。変えない)
- 判定AIに文章を書かせない。選択肢から選ぶ用途だけ

## 定例

- 毎朝 7:00 に `node sort.mjs --apply`(ローカルのタスクスケジューラ / launchd)
- 成功したら GAS に生存報告。見張り役は毎朝 9:00 に A1 を見て、30時間より古ければ Discord に警告

## 作業の始めと終わり

- 最初に `docs/STATUS.md` を読む。終わったら更新する
- 設計を変えるときは `docs/design.md` の4つの答えを直してから、コードを直す。理由は `docs/decisions/` に1ファイル
