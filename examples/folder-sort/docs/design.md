# 設計図: ダウンロードフォルダ整理

作る前に決めた4つ。変えるときはここを先に直す。

| 質問 | 答え |
| --- | --- |
| どこで動かす？ | ローカル。触りたいのは自分の PC の中のファイルなので、クラウドからは手が届かない |
| 誰がやる？ | 拡張子・日付の振り分け = プログラム。「請求書 / 領収書 / その他」から選ぶ = 判定AI(JEV)。ルールを考える・コードを書く = 生成AI(作るときだけ) |
| どう見張る？ | ステップ1: `logs/sort.log` に毎回1行(0件でも)。ステップ2: Discord に完了通知、失敗はメンション。ステップ3: 成功時に GAS へ生存報告し、別の場所の見張り役が30時間以上来なければ警告 |
| どう引き継ぐ？ | `AGENTS.md`(短い掟)+ `docs/STATUS.md`(現状・次の一手)+ `docs/decisions/`(なぜそうしたか)。会話には残さない |

## 止まったら誰が困るか

自分だけ。数日放置しても Downloads が散らかるだけ。なので見張りはステップ2まででも足りるが、ステップ3の見本として入れている。
